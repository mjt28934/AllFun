# AllFun 0.7.3

A navigation and layout cleanup. Home is gone, Sources is gone, and the three content tabs
now show only real content shelves instead of automatically generated history rows.

The library, progress, extensions, repositories, downloads and every source type are
unchanged. Existing installations update in place.

## What changed

- **Home removed.** The bottom bar is now five destinations: Movies, Books, Manga, Library
  and Settings. Movies is the start destination. The Home screen, its view model, its route
  and the Home shelf preferences were deleted.
- **Sources removed from the interface.** Settings no longer has a Sources button or a
  separate Sources screen. Extension, add-on and provider management lives in the
  Extensions screen, still reached from each category toolbar and from Settings.
- **Quick add beside Extensions.** A **+** button now sits immediately to the right of the
  Extensions icon on Movies, Books and Manga. It adds a Stremio addon, a Jellyfin server, a
  manga extension APK or a novel plugin over the same real dialogs and file pickers.
  **Discover extensions is not in the + menu**; Discover remains a tab inside Extensions.
- **Category tabs cleaned up.** Continue watching, Continue reading, reading history and
  Recently added were removed from Manga, Movies and Books. Extension-provided shelves such
  as Popular and Latest updates stay, as do search, filters, sorting, genre navigation,
  Watchlist, Favorites and every individual title.
- **Home settings and backup field removed.** The Home shelves switches no longer exist and
  new backups no longer contain `homeSections`. Restoring an older backup still works: the
  unknown field is ignored and the library is restored normally.

Nothing was deleted from the content database, and no provider integration was removed.

## Verified on the release build

- Signed 0.7.3 (`versionCode 703`, `versionName 0.7.3`, `CN=AllFun`) installed over 0.7.2
  with the library, installed extensions and downloads kept.
- Bottom navigation shows exactly Movies, Books, Manga, Library and Settings; the app opens
  on Movies and Back from another tab returns to Movies.
- Settings contains no Home or Sources controls. The Extensions section and screen remain,
  including the Discover, Installed, Updates and Repositories tabs.
- The **+** menu opens with Stremio addon, Jellyfin server, Manga extension (.apk) and Novel
  plugin (.js); the Stremio/Jellyfin dialogs and the APK file picker open. No Discover entry
  was added to the menu.
- Manga still loads real extension shelves and titles. Library still lists saved media and
  its scopes. Movies and Books keep their real empty states with **Manage extensions**.
- `:app:testDebugUnitTest` passes 36/36. Logcat shows no crash, ANR or navigation
  destination error.

## Install

1. Download `AllFun-0.7.3-release.apk` below.
2. Confirm the SHA-256 against `AllFun-0.7.3-release.apk.sha256`.
3. Open the file and let Android install it over 0.7.2. From inside the app, use
   **Settings → About → App Updates** instead.

Same certificate and package as every previous release, so your library, progress, settings,
extensions, repositories and downloads are kept.

## Notes

- Package remains `app.allfun`; `versionCode` 703, `versionName` 0.7.3.
- A fresh install remains empty: no demo titles, no bundled content and no invented shelves.
- Removing the Home screen does not remove media or history records. They remain available
  through Library and the category tabs.
