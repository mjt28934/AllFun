# v0.9.2 — a quieter Library, a Settings hub, one action row

This release removes the extra filter row from the Library, rebuilds Settings as a hub of
short, focused screens in Komikku's style, and puts the five catalogue actions on one line.
It also fixes the defects that surfaced while reading through every screen.

## What changed

### Library

- **The scope chip row is gone.** "Everything / Downloaded / Favorites / Recently added /
  Recently opened" sat under the content-group chips and did the same job less clearly.
  Content-group chips, the Continue strip and the grid remain; the scope state and its
  empty-state branches were deleted, not hidden.

### Category headers — Movies, Books and Manga

- **Five actions, one row.** Search, filter, refresh, extensions and quick-add now share a
  single right-aligned row beneath the title and tagline, so long names such as
  "Manhwa & Manga" keep their full width and the controls line up.
- **Search keeps the grid.** Search results used to fall back to two oversized columns.
  Browse, search results and the loading skeleton share one minimum cell width, so the
  column count stays the same from the first placeholder to the last result.

### Settings

- **A hub instead of one long page.** Appearance, Library, Reading, Playback, Downloads,
  Extensions, Storage, Network, Backup, App updates and About each show their current
  value as a subtitle and open a short dedicated screen. A search field filters the rows by
  title, subtitle and keywords. The download queue, extension manager and update screen are
  unchanged and still open from here.
- **Back returns to your place.** The hub keeps its scroll position when a sub-screen
  closes.
- **Novel sliders are continuous.** They no longer render as a row of tick dots, and the
  value is written once when you lift your finger rather than on every dragged pixel.
- **Storage reports the real database size.** It measured the wrong directory and always
  showed 0 B for the library database.

### Detail pages

- **Action labels are not clipped.** "Add to library" no longer truncates to
  "Add to libr…" on manga and book detail pages; labels wrap to two centred lines.

## Breaking changes

- None. Library, history, extensions/providers, downloads, backups and integrations are
  untouched; the database schema does not change in this release.
