# AllFun 0.6.0

The polish release. The three-category model introduced in 0.5.0 is unchanged; 0.6.0
reworks how it looks, moves and reads, makes the extension manager legible, and fixes the
places where the UI contradicted the data.

## Highlights

- **Redesigned dark-first UI.** Deeper ink surfaces, warmer amber accents, a new type scale
  (32 sp display, 25 sp page titles, 21 sp section titles), 16/22 dp shapes, clearer
  elevation and consistent 16–20 dp page margins. Cards, shelves, dialogs, sheets and
  settings rows all share the same primitives.
- **Real motion, with an off switch.** A single `Motion` token set drives screen transitions,
  the sliding bottom-navigation pill, press feedback, content reveals, progress animation
  and expand/collapse. `Settings → Accessibility → Reduce motion` (or Android's animator
  duration scale) disables all non-essential animation.
- **Home built only from real content.** Continue watching/reading, favorites, recently
  opened, recently updated and recently added are the only shelves. Each can be hidden in
  Appearance, empty shelves disappear, and category cards show saved counts, connected
  sources and source issues from live data. No recommendations are invented.
- **Category screens.** Rounded search, source and format chips, a sort menu (source order,
  title A–Z/Z–A, by source), a filter sheet with clear-all, adaptive poster grids, the
  continuing shelf for the current category, and distinct loading, empty, no-source and
  error states. Browse-all keeps the sort and filters.
- **Global search history.** Committed searches are stored locally (newest first, no
  duplicates, eight entries), shown as removable chips, and only a real response is ever
  reported. Category and source filters remain available.
- **Extension manager.** Installed extensions are grouped by content type, sorted by name,
  and show icon, name, version, developer, repository host, content type, 18+ marker and
  status. Search works on Installed, Discover and Disabled; details open in a bottom sheet
  with version, permissions, source ids and actions.
- **Accessibility.** 48 dp touch targets, spoken labels for icon-only controls, tab semantics
  on the bottom bar, live regions for errors, `stateDescription` on expand/collapse and
  progress, and text that wraps at large font scales instead of clipping.

## Fixed in 0.6.0

- **A finished video no longer sits in Continue watching at 100%.** Movies at the end of
  their progress are excluded.
- **Continue shelves only contain playable content.** Media whose source row is missing or
  disabled (for example after restoring a backup onto a device that lost its sources) is
  hidden instead of opening a dead detail screen.
- **Installed extensions are reconciled with the source table at startup.** An APK that is
  present on disk but has no database rows is registered again, so the Extensions screen and
  the category screens agree instead of one listing two extensions and the other saying
  "no source".
- **A local source with nothing imported is no longer reported as an issue.**
  "Imported books — Returned no titles" is gone; an empty local catalogue is an empty
  shelf, not a failure.
- **Library and category section actions point where their labels say.** "Library" opens the
  Library instead of the first item in the shelf.
- **Category destinations behave like destinations.** Opening a category from Home then
  pressing Back returns Home instead of walking through previously visited tabs.
- **Search history is accurate.** Typing prefixes are not recorded; only a submitted search
  or a tapped history chip is saved. The idle screen now opens at the top, so recent
  searches are never hidden behind the results list's old scroll position.
- **Filter facets fill in as they arrive.** Opening Filters on a large catalogue no longer
  waits for every detail request before showing anything: format, genre, year and author
  chips appear in batches while the remaining metadata is still loading.
- **Category actions no longer squeeze the title.** Sort, filter and refresh moved to the
  status row, so "Manhwa & Manga" is no longer truncated to "Manhwa & …" on a 360 dp screen.
- **The bottom-bar indicator tracks the icon.** The selection pill sits behind the icon and
  follows it when the system font scale changes, instead of clipping the selected label.
- **Repository languages are readable.** Discover shows "Thai" or "English" instead of the
  raw index codes "th" and "en".

## Install

1. Download `AllFun-0.6.0-release.apk` below.
2. Confirm the SHA-256 against `AllFun-0.6.0-release.apk.sha256`.
3. Open the file and let Android install it over 0.5.0. From inside the app, use
   **Settings → About → App Updates** instead.

Existing installations signed with the same release key update in place; the library,
chapters, progress and settings are preserved.

## Verified on the release build

- Signed 0.6.0 (`versionCode 600`, same certificate) installed over 0.5.0 with the library,
  chapters, progress and settings intact.
- Five destinations and three categories; live Home counts; category search, the four-way
  sort menu and filter facets that fill in while metadata loads.
- Global search groups real results by category with provider labels and source chips;
  committed searches survive a force-stop and appear under Recent searches.
- Extensions: Installed (2, grouped by type, statuses and versions), Discover (2,086
  extensions from 2 repositories), Updates ("Everything is up to date" after comparing
  2 installed items with 2 repositories), Repositories (real URLs and counts), details
  sheet, disable → re-enable.
- Reduce motion persists across a relaunch; `:app:testDebugUnitTest` passes 30/30 and the
  crash buffer stayed empty through the pass.

## Notes

- The package is still `app.allfun` and the signing certificate is unchanged.
- `versionCode` is 600, `versionName` 0.6.0.
- A fresh install remains empty: no demo titles and no invented shelves.
- Offline downloads are not implemented and the Downloads section says so instead of
  offering a toggle that does nothing.
