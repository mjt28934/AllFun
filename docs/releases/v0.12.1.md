# AllFun v0.12.1 — Quiet Reading Room

A visual redesign for a denser, calmer library across movies, books, manga, settings and extensions. Source, library, reader and playback behavior stays the same.

## What changed

- Replaced the stock purple and teal styling with warm dark and light palettes, editorial headings, compact UI typography, bundled Newsreader, Hanken Grotesk and IBM Plex Mono fonts.
- Rebuilt the top area, bottom navigation, buttons, chips, tabs, search field, settings groups and sheets around consistent spacing and hairline structure.
- Added distinct line illustrations and short, task-focused copy for empty library, browse, extension, update, repository and search states.
- Tightened the library to a three-column cover grid by default, with progress and type marks.
- Grouped settings and exposed current values; simplified About and update status.
- Kept the existing Movies, Books, Manga, Library and Settings destinations and source logic.

## Install

Download `AllFun-0.12.1-release.apk` below. Confirm its SHA-256 against `AllFun-0.12.1-release.apk.sha256` before installing. Existing release-signed installations update in place.
