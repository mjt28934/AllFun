# v0.12.0 — the Aurora UI pass and a new mark

This release is the visual overhaul: every main screen now shares one motion language, one
card language and one accent system, and the launcher icon is rebuilt as a layered,
gradient-backed adaptive icon. Nothing about the library, providers, downloads, backups or
settings changes underneath.

## What changed

### Motion

- **One motion scale.** `Motion.kt` now carries emphasized easing, a snappy spring, a settle
  spring and a stagger helper. Presses, selections and page changes all draw from it.
- **Theme changes animate.** Switching theme, accent, corners or text size no longer repaints
  the whole app in one frame: the 14 key Material colours tween into each other.
- **Page transitions.** Moving between the five destinations slides and scales the outgoing
  and incoming screens; detail, search and reader screens lift in from just under full size.
  Back navigation reverses the movement instead of cutting.
- **Reduce motion is still honoured.** Every new animation checks the existing preference and
  the platform animation setting.

### Navigation

- **A floating bottom bar.** The bar is now a rounded, softly bordered surface with one
  gradient pill that travels to the selected destination, a small icon bounce, a haptic tick
  and no ripple rectangles. It sits above the navigation bar instead of running edge to edge.

### Browse

- **Collapsing category hero.** The collection name, tagline and real counts live in a
  gradient card inside the grid, with a slow parallax glow. When it scrolls away, the fixed
  top bar takes over the category name, so the context never disappears.
- **Segmented sort bar.** Popular / Latest / A–Z / Rating are one control with a sliding
  selection instead of loose chips.
- **Staggered grid.** Cards reveal in a short wave as the grid opens, animate their own
  insert/remove/move, and carry a thin rim plus a two-stage scrim so badges and progress stay
  legible over bright artwork.
- **Gradient progress.** Every progress bar now uses the accent-to-secondary gradient and
  glides to its value instead of snapping.

### Detail and reader

- **Immersive heroes.** Film and reading pages use a taller backdrop, a deeper multi-stop
  scrim, a bordered floating cover, larger type and the category accent. The app bar starts
  transparent and gains its surface only after the hero leaves.
- **Animated rows.** Episode, chapter and source rows stagger in and animate their position;
  the play/read actions are taller, rounded and aligned to the same shape language.
- **Reading chapters** now use the same collapsing bar, staggered reveal and rounded action
  row as video details.

### Library, downloads, settings, search, extensions

- **Library**: a gradient header mark, animated count line, staggered grid and list rows.
- **Downloads**: a queue summary card (active, saved, failed, concurrency), gradient progress
  in group headers and rows, and staggered queue entries.
- **Settings**: a gradient hub header, icon badges on every entry, press-scale feedback and a
  staggered list; appearance options keep working as before.
- **Search**: an installed-source count pill, a rounded search field and the existing grouped
  result rows.
- **Extensions**: installed and update lists stagger in and animate row moves.

### Icon

- **New adaptive icon.** Two fanned media cards — a cyan library card behind a violet,
  gradient-lit play card — over a deep indigo field with violet and cyan aurora glows. The
  mark is drawn inside the 66dp safe zone, so circle, squircle and rounded-square launchers
  all keep the glyph intact.
- **A dedicated monochrome layer** keeps themed icons readable: line-art cards plus a solid
  play mark, instead of reusing the coloured artwork as a mask.
- The splash screen keeps using the foreground, so the new mark also appears at launch.

## Breaking changes

- None. Database schema, preferences, providers, addons, downloads and backups are unchanged;
  every route and control that existed before still opens the same screen.
