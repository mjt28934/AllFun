# v0.9.1 — one vertical catalogue, honest sorting, calm readers

This release turns the three category screens into a single vertical catalogue, makes
Popular and Latest real, first-class sort orders, and stops reader chrome from flashing
while you scroll. It also renders provider Markdown as prose on manga and book detail
pages.

## What changed

### Category screens — Movies, Books and Manga

- **One vertical adaptive grid.** The horizontal shelf carousels and the separate
  "browse all" screen are gone. Every provider result arrives in one grid that scrolls in
  one direction, so no title is hidden behind a sideways swipe.
- **Popular and Latest are first-class.** The chip row under the header offers
  **Popular**, **Latest**, **A–Z** and **By source**. Popular and Latest rank by the
  shelves the providers actually returned (`POPULAR`, `TRENDING`, `LATEST`, `RECENT`,
  `OTHER`); titles missing from those shelves follow in source order. Nothing is
  re-ranked by a hidden score.
- **Header counts are visible.** The header carries the result count, the number of
  contributing sources, a separate issue count, and a **Filtered** pill when a facet is
  active.
- **Favorites and watchlist stay in the grid.** Up to six preview rows appear under a
  full-width section header with a **Library** action that opens the Library tab.
- **Filters stay in the sheet**, with the list updating behind it; loading more and
  provider issues are full-width rows in the grid footer.
- **Search failures are summarised.** A failed provider search shows one
  "3 sources could not be searched" line with a Details toggle instead of a stack of
  error strings.

### Readers

- **Chrome no longer toggles on touch-down.** The manga vertical reader flashed its bars
  on the first pointer down. It now requires a real tap, ignores tap-to-stop-a-fling for
  180 ms, and hides the bars when a scroll actually starts.
- **Novel taps are detected inside the document.** Compose pointer input over a WebView
  does not reliably see touches, and taps that stopped a scroll toggled the bars. The
  injected reader script now reports a tap only when the finger moved less than 12 px for
  less than 350 ms, skips links, and ignores the programmatic scroll used to restore
  position.
- **Scrolling hides the chrome** in both readers; a deliberate tap brings it back. Paged
  manga keeps its tap zones: left/right page or chapter, centre chrome.

### Detail pages

- **Provider Markdown renders as prose.** Weeb Central and similar sources write
  descriptions as Markdown, so sequel lists appeared as
  `[Wanted!](https://weebcentral.com/series/…)`. Link labels are kept, URLs and
  emphasis/heading markers are dropped, and paragraphs stay intact.

### Library

- **The sort menu reads at a glance**: each order has its own glyph (updated, added,
  opened, title, author) and only the current one is tinted with the accent.

### Docs and tests

- New `docs/UI_REVIEW.md` records what was inspected, what changed, the remaining P0–P2
  backlog, and the measurement and accessibility checks still to run.
- `:app:testDebugUnitTest` now covers category lane sorting and description flattening
  (65 tests).

## Breaking changes

- None. Library, history, extensions/providers, downloads, backups and integrations are
  untouched; the database schema does not change in this release.
