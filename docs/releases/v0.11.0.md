# v0.11.0 — playable movie details, a queue that keeps going, more appearance

This release fixes the two things that blocked normal use — a movie detail screen that listed
sources but never showed anything to play, and a download queue that stopped after the first
few items — and fills in the rough edges around chapter labels, category sorting, long lists
and addon installation. Appearance gains an accent palette, corner style and app text size,
and motion settles instead of stopping.

## What changed

### Movie details

- **Episodes and sources now appear.** When a Stremio catalogue card is opened and no
  installed addon answers `meta` for that id, the detail screen builds one playable unit from
  the card's own id (`movie|tt…` → `tt…`). Sources are no longer dead ends: tapping one plays
  the film, and the existing provider preference still decides which addon is tried first.
- The fallback is limited to movies, so series and books never get a fake single episode.

### Downloads

- **The queue no longer stalls after the first few items.** A finished worker now pumps the
  queue itself, so the next waiting chapter starts whether or not another network or enqueue
  event happens. Ten queued chapters download as ten, without cancelling and re-tapping.
- Pause, resume, concurrency and Wi-Fi-only behaviour are unchanged.

### Chapter labels

- **No more "Chapter -1.0".** When a source has no real chapter number, the subtitle shows the
  page count, duration or the source's own numbering instead of a negative placeholder.
- Real numbering is still shown when the source provides it.

### Categories

- **Popular / Latest actually reorders.** Latest prefers the provider's own recent shelves; when
  a provider exposes only one lane, titles are ordered by the release year parsed from the card
  metadata, then by title. Popular keeps the provider's ranking.
- **Load more is stable.** Extra pages are deduplicated by the same key the grid uses, skip
  titles already on the first page, and stop at 3,000 items instead of growing without bound.
  Sorted and filtered lists are memoised, so scrolling a long grid no longer re-sorts on every
  recomposition.

### Extensions

- **Install Stremio addons without pasting a URL.** Discover → Video now has a one-tap
  directory: Cinemeta, Torrentio, Comet, MediaFusion, OpenSubtitles v3 and WatchHub, each with
  its role (metadata, streams, subtitles), an Install button and an installed check. Pasting a
  manifest URL remains available for anything not listed.
- Installing one row only spins that row; the rest stay usable.

### Appearance

- **Accent colour**: Violet, Ocean, Emerald, Amber or Rose, used whenever Material You colour
  extraction is off.
- **Corner style**: Rounded, Soft or Sharp, applied to cards, sheets, buttons and dialogs.
- **Text size**: System, Compact, Large or Extra large, layered on top of Android's own font
  scale.
- Material You, pitch black, theme mode and reduce motion are unchanged.

### Motion

- Press feedback and the bottom-bar pill now settle with a short spring instead of a fixed
  duration, so scaling and sliding arrive smoothly without overshoot. The selected tab icon
  keeps a small amount of give.
- Reduce motion still turns all of it off, including the platform "remove animations" setting.

## Breaking changes

- None. Library, history, extensions/providers, downloads, backups and integrations are
  untouched; the database schema does not change and no preference is removed or renamed.
