# AllFun 0.5.0

The three-category redesign. AllFun now has exactly three content destinations — **Movies &
Shows**, **Books & Novels** and **Manhwa & Manga** — and every extension, addon, manga
source, novel plugin, Jellyfin server and local folder feeds one of them in the background.
No source is a tab any more.

## Highlights

- **One home, three categories.** Bottom navigation is
  Home · Movies & Shows · Books & Novels · Manhwa & Manga · Settings. A provider can only
  contribute to the category that matches its kind; adding an extension never adds a tab.
- **Unified feeds.** `ContentRepository` aggregates every enabled source of a kind, publishes
  partial shelves as each provider answers, merges duplicate titles while keeping every
  confirmed provider, paginates round-robin, and caches feeds, searches and details.
- **Unified search.** Every compatible installed source is searched at once; results are
  grouped into the three categories, deduplicated, labelled with the provider, and filterable
  by category or source.
- **Source selector on details.** A title lists the other sources that confirmed it, with
  availability and error status. Only an exact title match counts. You can set a preferred
  source per title and it is remembered.
- **Category filters from real metadata only.** Format, genre, year, author and source
  filters appear when the sources actually provide those fields.
- **Extensions stay in Settings → Extensions** (Installed · Discover · Updates ·
  Repositories · Disabled) with install, update, configure, enable, disable, uninstall and
  permissions.

## Fixed in 0.5.0

- **A hung provider no longer freezes a category.** Per-request deadlines now use
  `withTimeoutOrNull`; a cancelled request used to propagate as a cancelled feed and left the
  screen spinning. Each feed also has a 45 s budget and search a 30 s budget, and providers
  are interleaved so one extension with dozens of language variants cannot starve the rest.
- **Release crash on `Content-Encoding: zstd`.** R8 had stripped
  `com.squareup.zstd.ZstdCompressor`, which OkHttp 5 resolves from native code. The class is
  now kept, so a zstd response no longer aborts the process.
- **MangaDex requests returned HTTP 400.** AllFun's page numbers are 0-based and Tachiyomi's
  are 1-based; the adapter now converts explicitly instead of sending `offset=-20`.

## Install

1. Download `AllFun-0.5.0-release.apk` below.
2. Confirm the SHA-256 against `AllFun-0.5.0-release.apk.sha256`.
3. Open the file and let Android install it over 0.4.0. From inside the app, use
   **Settings → About → App Updates** instead.

Existing installations signed with the same release key update in place; the library,
chapters, progress and settings are preserved.

## Notes

- Upgrading from 0.4.0 keeps the library, chapters/episodes, progress and settings. The
  signing certificate is unchanged.
- A fresh install is still empty: no demo titles, no seeded rows.
