# AllFun 0.4.0

First public release, numbered 0.4.0. AllFun is one Android app for manga, light novels,
movies and series: a single library, one progress record per title, and sources that range
from local files to Jellyfin, Stremio addons, Tachiyomi/Mihon extensions and LNReader
plugins.

## Highlights

- **One shelf for every medium.** Home shows a mixed Continue row plus sections that only
  appear when they have data. Library filters by kind, searches, sorts and favourites.
- **Real sources, not placeholders.**
  - EPUB import and folder-based local video import (persisted SAF permission).
  - Jellyfin catalogue, episodes and direct-play streams.
  - Stremio addon protocol: manifest, catalog, meta, streams, subtitles, proxy headers.
  - Tachiyomi/Mihon/Komikku extension APKs against AllFun's own `eu.kanade.tachiyomi.*`
    host ABI, signature-checked when installed from a repository.
  - LNReader JavaScript plugins in an offscreen WebView with a real `fetch` bridge.
- **Readers and player.** Vertical, paged and right-to-left manga with zoom; EPUB and
  network chapter text in a themed WebView; Media3 playback with resume, subtitles,
  next episode and readable errors.
- **Backup and restore.** One JSON file with settings, repository URLs, library, chapters
  and progress. Credentials and extension code are deliberately excluded.
- **GitHub-based updates.** Settings → About → App Updates checks the published releases
  of this repository, verifies the APK's SHA-256, package identity and signing
  certificate, then hands it to Android's own installer. Launch checks and a 12-hour
  WorkManager job are on by default and can be switched off.
- **No bundled catalogue.** A fresh install is empty: no demo manga, no sample book, no
  seeded rows. Every title comes from a source you added.

## Install

1. Download `AllFun-0.4.0-release.apk` below.
2. Confirm the SHA-256 against `AllFun-0.4.0-release.apk.sha256`.
3. Open the file and let Android install it. From inside the app, use
   **Settings → About → App Updates** instead.

## Verify the signature

Every release is signed with the same certificate, so it installs over an earlier version
and keeps its library. Android refuses an APK signed with any other key.

```
77def786ae61b45f030689aa8d41835033aa6d668ef00f00f2f749b5e68868c2   CN=AllFun
```
