# AllFun 0.7.0

The release that finishes the app it kept promising. Navigation is now exactly six real
destinations, local media is gone, extensions are installed from the category they belong
to, and downloads actually download and read offline.

## Highlights

- **Six destinations, no exceptions.** Home · Movies & Shows · Books & Novels ·
  Manhwa & Manga · Library · Settings. Extensions, providers and repositories are never a
  tab; they open from the toolbar of the category they feed or from Settings.
- **Local media removed.** Imported EPUBs, folder-scanned videos, the local-media chips,
  filters, counts and selection are all gone from the code, the database cleanup and the
  copy. The Sources screen only adds remote providers now.
- **Library is a real library.** All / Movies / Books / Manga, plus Everything / Downloaded /
  Favorites / Recently Added / Recently Opened scopes. Cards show how many chapters or
  episodes are on disk, the size and the completion date; search, sort, remove-download and
  open still work.
- **Offline downloads, end to end.** Manga chapters are stored as page folders with a
  `pages.json` manifest, novels as saved chapter HTML, and direct HTTP video files are
  streamed to disk with real progress. HLS/DASH manifests (`.m3u8`, `.mpd`) are refused with
  a plain sentence instead of a fake download. Completed downloads appear in the Library
  immediately, survive a restart, and never create duplicate or half-written rows.
- **Settings → Downloads is the download manager.** Active, queued, completed and failed
  sections, real progress, pause/resume/retry/cancel/remove, clear-finished, Wi-Fi-only and
  a concurrency limit. Destructive actions ask first.
- **Category toolbars are compact.** Title, one-line description, search, filter, refresh and
  the extension button on the right; filters and sort live in bottom sheets instead of
  permanent chip rows.
- **Extension marketplace, category-aware.** The toolbar button on Movies, Books or Manga
  opens the marketplace already scoped to that category with the search field focused.
  Filters are All / Available / Installed / Updates / Compatible; sections are Discover,
  Installed, Updates and Repositories; install, update, disable, uninstall, details and
  declared permissions all work.
- **Source states instead of raw failures.** Each failing provider is reported as
  Temporarily unavailable, Auth required, Invalid response, Disabled or Unsupported, with
  Retry and a separate technical-details disclosure. One provider failing no longer hides
  the others.

## Fixed in 0.7.0

- **HTML served with a JSON content type no longer crashes parsing.** Responses are checked
  for status, content type and body shape; an HTML page, a doctype, an empty body or
  malformed JSON becomes a readable "Invalid response" error with the evidence kept in
  technical details.
- **Chapters sort in reading order.** Extensions that report `chapter_number = -1` and only
  put the number in the title used to list "1009, 101, 1010 …"; the number is now read from
  the title.
- **Downloaded chapters open offline.** Downloads are keyed by the local episode row, so a
  provider that changes its chapter URL no longer makes the offline copy unreachable. The
  reader and player also ask the download store before the network.
- **Download state is written once per change.** Pause, cancel and remove join the worker
  before writing, so a late progress tick cannot resurrect a deleted row.
- **No oversized search field or permanent filter rows** on the category screens, and no
  provider-name clutter over posters.
- **Library counts, badges and download dates come from the download table**, not from
  optimistic UI state.

## Install

1. Download `AllFun-0.7.0-release.apk` below.
2. Confirm the SHA-256 against `AllFun-0.7.0-release.apk.sha256`.
3. Open the file and let Android install it over 0.6.0. From inside the app, use
   **Settings → About → App Updates** instead.

Signed with the same certificate as every previous release, so the library, progress,
settings, installed extensions, repositories and existing downloads are kept.

  installed over the previous build with the library and extensions intact.

  focused and lists the real index (373 book plugins from 2 repositories); opened from
  Manhwa & Manga it lists the manga catalogue.

  20+ pages, visible as `COMPLETED` in the database with a real folder path; a second

- With Wi-Fi and mobile data disabled, the downloaded chapter was opened from the Library
  and every page rendered from local storage; the undownloaded chapter still reported
  "Can't reach that server" with Retry.
- Force-stop and relaunch: both downloads were still listed with their sizes, no duplicates,
  and removal deleted the row and the folder.
- Settings → Downloads showed both completed items, the Wi-Fi toggle, the concurrency
  stepper and a confirmation before deleting files.
- `:app:testDebugUnitTest` passes and the release crash buffer stayed empty through the pass.
