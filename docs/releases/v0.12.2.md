# AllFun v0.12.2 — Bottom bar layout fix

Fixes a layout regression that expanded the bottom navigation over the entire screen, hiding the active screen and placing the tabs around the middle of the display. The bottom navigation now has a fixed 64 dp content row above the system navigation inset.

## Install

Download `AllFun-0.12.2-release.apk` below and verify its SHA-256 against `AllFun-0.12.2-release.apk.sha256`. Existing release-signed installations update in place.
