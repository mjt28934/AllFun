# v0.9.0 — Komikku-style manga and book detail pages

The manga and book/novel detail screens are rebuilt to match Komikku's layout and behavior. The movies detail screen is unchanged.

## What changed

### New detail screens — Manga and Books
- **Backdrop header**: cover art, title, author, artist (manga), status, year, and source name, with a gradient overlay.
- **Action row**: Add to library / In library, Favorite / Favorited, Download / Downloaded, and Sources — all with tinted icon+label buttons.
- **Expandable description**: up to 6 lines or a "Read more" / "Show less" toggle when the description exceeds 280 characters.
- **Genre tags**: `FlowRow` of chip surfaces for tags.
- **Chapter list with sorting and filtering**:
  - Read chapters shown dimmed with no blue dot; unread chapters show a primary-blue indicator.
  - Per-chapter progress percentage (e.g. "36%") shown inline.
  - Source order, Newest first, Oldest first sorting.
  - All / Unread / Downloaded filters.
  - Accessed via a tune icon header button opening a dialog with radio buttons and filter chips.
- **Floating Action Button**: "Start" shown when no chapter is read, "Resume" when progress exists — navigates to the next unread chapter or the one with saved progress.
- **Long-press chapter action sheet**: Read now, Mark as read / unread, Download / Cancel / Retry / Remove download.
- **Overflow menu**: Refresh, Mark all as read, Available sources.
- **Source sheet**: `ModalBottomSheet` listing available provider options, with loading/error states and a retry button.

### New reader screens — Manga and Books

- **Manga reader**:
  - **Modes**: vertical scroll or paged (left-to-right / right-to-left), fit width / fit height / whole page, pinch-to-zoom and pan.
  - **Chrome**: tap zones in paged mode — left/right thirds turn the page or switch chapter, center toggles chrome; a thin bottom progress bar; slide-in/out top and bottom bars; volume keys page up/down (respects page order).
  - **Settings sheet**: reading mode, fit pages, page order; changes apply live without reloading the chapter.
  - Chapter picker (searchable), per-page read markers, read-on-open tracking via `EpisodeEntity.read`.
- **Novel reader**:
  - Single WebView for downloaded and network chapters. Live typography: Dark / Sepia / Light themes, font size and line spacing applied without reloading.
  - Thin bottom progress bar (0–100%), slide chrome, volume keys scroll by ~75% of a screen.
  - Searchable chapter picker; per-chapter scroll position saved and restored on resume; chapter marked read on open.

### Infrastructure
- `ReadingDetailScreen.kt`: new composable dispatcher for manga and books detail, implemented alongside the existing `MoviesDetailScreen`.
- `ReadingChapterOrder.kt`: pure-function sort/filter (`ChapterSort`, `ChapterFilter`, `orderedChapters`, `filteredChapters`).
- `DetailViewModel`: added `sourceName` flow, `setRead`, `markAllRead`, `refreshNow`.
- `EpisodeEntity.read`: DB migration v7 adds a real per-chapter read column, backed by `EpisodeDao.setRead`/`setAllRead`.
- Reader VMs (`MangaReaderViewModel`, `NovelReaderViewModel`): mark a chapter as read when it's opened.
- `DetailScreen.kt`: refactored into a dispatcher (`DetailScreen` → `DetailLoading` / `MoviesDetailScreen` / `ReadingDetailScreen`).
- `SourceOptionRow` made `internal` for reuse in the reading source sheet.
- Backup format carries the `read` field.

### Bug fixes
- Combined click on chapter rows correctly supports both tap (navigate) and long-press (action sheet).
- Download indicator shows progress circle for downloading, checkmark for completed, error icon for failed, and a retry button.

### Breaking changes
- None deliberately. The library navigation, download queue, extension loading, backups, and reader integration all remain. The database schema advances to v7 (automatic migration).
