# AllFun 0.7.1

A small patch on top of 0.7.0. It changes one thing: the bottom navigation indicator.

## What changed

- **The tap glow is gone.** Tapping or hovering a bottom-bar tab no longer paints the grey
  ripple/hover rectangle around it.
- **The sliding pill stays.** The filled primary pill still glides to the selected
  destination and sits behind its icon. Selection animation, colour change and icon fill
  are unchanged.
- **Reduce motion still applies.** With reduced motion on, the pill snaps to the new tab
  instead of sliding.

Nothing else changed: sources, downloads, the Library, the marketplace, the reader and the
player are the same as 0.7.0.

## Install

1. Download `AllFun-0.7.1-release.apk` below.
2. Confirm the SHA-256 against `AllFun-0.7.1-release.apk.sha256`.
3. Open the file and let Android install it over 0.7.0. From inside the app, use
   **Settings → About → App Updates** instead.

Same certificate and package as every previous release, so the library, progress, settings,
extensions, repositories and downloads are kept.
