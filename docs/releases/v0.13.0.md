# v0.13.0 — Liquid Glass

The interface is rebuilt around one material: dark warm glass over a static world. The
library, providers, extensions, downloads, backups, playback and settings keep working the
same way; what changed is how every screen is put together.

## What changed

### The material

- **One world behind every screen.** `bg0 #0A0B0E` plus four soft section-tinted radial
  blobs and 2–3% grain. The field is pinned: it never scrolls, loops or animates.
- **Three glass tiers.** Clear for floating capsules and controls, frosted for panels and
  sheets, inset for tracks and wells. No glass is placed on glass; each group has one panel.
- **A single surface recipe.** Lens of the world, warm tint, top edge sheen, 1dp inner
  shadow, single soft drop shadow, optional 900ms specular sweep at High.
- **Warm neutrals and section hues.** Movies pink, Books teal, Manga violet, Library amber,
  System stone. Status colours always come with text or an icon.

### Type and icons

- **Fraunces + Inter Tight**, both bundled OFL variable fonts. Display, title, heading,
  body, caption, overline and tabular numerals are one scale.
- **A hand-drawn monoline icon set** (24dp, 1.75dp stroke) replaces Material icons in the
  UI layer. Icons sit bare on glass: no coloured tiles, no filled badges.

### Navigation and shell

- The bottom bar is a 64dp glass capsule with a travelling blob, hide-on-scroll and haptic
  ticks. It floats over content; every tab reserves room so no row is clipped.
- Each destination draws its own world and its own section accent. Transitions are fades,
  with small slides for tabs and a 320ms entry for deeper screens. Reduce Motion keeps only
  crossfades.

### Screens

- **Browse** — no collection hero, no filter-chip noise, no "Load more". Fixed adaptive
  3-column grid, automatic loading near the end, sort capsule and filter sheet.
- **Search** — a top capsule, category and source chips, grouped poster rows, recent
  searches, skeletons and source issues on one panel.
- **Detail and reading detail** — hero panels, one primary action, about/source panels,
  bare chapter rows for long serials, Canvas download rings, glass sheets for sources,
  sorting and chapter actions.
- **Library and Downloads** — glass grids and rows; downloads are grouped per title with
  hairline rows and real queue controls.
- **Settings** — a hub of grouped panels, no gradient header, and a new **GLASS LEVEL**
  control with a live preview (High / Standard / Lite).
- **Extensions** — all five tabs, category scope, repository and addon panels, glass forms
  and details sheets.
- **Readers and player** — neutral reading/video canvas, floating clear top capsule,
  frosted bottom bar, glass chapter picker and reader settings. The player keeps Media3's
  surface and only replaces its controls.
- **Updates/About** — release panel, real download/verify/install progress and readable
  failure states.

## New setting

- `glass_quality` (`High` / `Standard` / `Lite`, default `Standard`) changes only how the
  material renders: world lens, grain, sweep and shadow depth. It is the only preference
  added in this release.

## Accessibility

- 48dp touch targets, `Role.Button` on glass actions, content descriptions on every icon,
  and text colours checked against the frosted body.
- Reduce Motion is honoured by every transition and by the specular sweep.
- Material You, light theme and AMOLED black still work; dynamic colour affects neutrals,
  not the section hue.

## Honest limits

- No GPU refraction shader: the glass is drawn with Compose/Canvas primitives so it works
  on minSdk 26 without sampling the window every frame.
- No frame-time table or per-screen screenshot matrix was produced for this release; see
  `DESIGN.md` for the design-level measures and the skipped deliverable list.
- The novel reading text stays on its paper theme; only the chrome is glass, because body
  text needs an opaque plane.

## Breaking changes

- None. Database schema, preferences, providers, addons, downloads, backups and routes are
  unchanged. Every previous action is still reachable; some moved into overflow sheets or
  capsules.
